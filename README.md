# Agenda\_De\_Tarefas\_GabThur\_Remasterizado

## Versão definitiva do programa, realizado pelos alunos do SENAI-RS Santa Cruz Do Sul Arthur Santos Lopes e Gabriel Heineck Haberkamp

Gabriel Haberkamp foi responsável por desenvolver a base do projeto: (primeiro repositório base em https://github.com/arthur07lopes/Agenda-de-tarefas-WxPython-GabThur.git), onde Arthur Lopes foi responsável por desenvolver as funções do programa da agenda de tarefas.

Também foi responsável pela criação do ícone na bandeja com as tarefas pendentes e as opções abrir / sair.

E por fim, Arthur Lopes fez uma nova criação de repositório e fez a revisão local do projeto utilizando o Microsoft Visual Studio Code, realizando a importação dos arquivos e reajuste da lógica do programa. Foi utilizado o wxPython para a realização da interface gráfica, onde é compatível com o NVDA, garantindo a acessibilidade do sistema para usuários com deficiência visual e permitindo uma navegação fluida por meio de leitores de tela.



# OBSERVAÇÃO!

\---

Para iniciar o programa, baixe o repositório através do botão "Code<>", depois "Download ZIP", exportar o arquivo através do Windows Explorer ou utilizando o software do WinRAR, e por fim, abrir a pasta exportada do repositório e executar o programa através do "main.py".
